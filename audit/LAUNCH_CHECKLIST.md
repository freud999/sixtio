### 5.2 Метрики, які дивимось (і звідки)

| Метрика | Джерело | Норма дня 1 |
|---|---|---|
| Клік → `start` | `/stats_sources` | ≥30% (нижче — проблема посилання або гейта) |
| `start` → `onboarding_complete` | `/stats` | ≥20% (прогноз фази 10: 1000 з 4000 = 25%) |
| Час онбордингу, медіана | ручний замір | <8 хв |
| 5xx на всіх ендпоінтах | Vercel Logs / Sentry | <0.5% запитів |
| p50 / p95 `/api/me` | Vercel | <1.5 c / <5 c |
| Supabase egress | Supabase Usage | лінійно до трафіку, **без стрибків** |
| AI-витрати | Anthropic + Gemini Billing | ≤$74 на 1000 онбордингів |
| `paywall_open` → `purchase` | `/stats` | будь-яке >0 у день 1 — уже сигнал |
| CAC | spend / purchase | має бути **менше** LTV, інакше масштабувати не можна |
| Звернень у підтримку | Telegram | ~20 на 4000 стартів; сплеск = симптом бага |

### 5.3 Умови ПАУЗИ реклами

**Негайна пауза (не чекаючи ранку):**
- 5xx > 5% протягом 10 хв, або health-проба червона >5 хв;
- Supabase CPU >80% або egress росте нелінійно (симптом SCALE-1);
- будь-яка ознака підробки платежів (баланс росте без `purchase` у `/stats`);
- CR `start → onboarding_complete` **< 5%** (гроші йдуть, продукт не працює);
- AI-витрати перевищили денний план **у 2 рази** (симптом абузу, SCALE-5);
- >3 однотипні скарги на втрачені гроші протягом години.

**Пауза до ранку (без нічної аварійної роботи):**
- CAC > 2× плану на вибірці ≥10 покупок;
- CR клік→старт < 15% (не туди веде посилання або гейт);
- 0 покупок при >200 `paywall_open`.

**Масштабуємо (×1.5, не більше) тільки якщо всі три виконані одночасно:**
CAC < LTV · 5xx < 0.5% · CR старт→онбординг ≥ 20%.
