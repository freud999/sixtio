# Sixtio — Смоук-тест перед увімкненням реклами

**Коли:** безпосередньо перед заливом бюджету, після кожного релізу в день запуску.
**Де:** **реальний телефон** (не десктоп, не емулятор), реальний Telegram-клієнт,
мобільна мережа (не Wi-Fi офісу).
**Ким:** 1 людина, ~40–50 хв.
**Правило:** будь-який ❌ у кроках 1–12 = **не вмикаємо рекламу**. ❌ у кроках 13–28
= вмикаємо з меншим бюджетом і фіксимо в перший день.

**Що підготувати:**
- два **чисті** Telegram-акаунти (A — жіночий профіль, B — чоловічий; потрібно для метчу);
- третій акаунт або десктоп для перевірки мов;
- телефон із мовою системи, відмінною від української (для перевірки en);
- доступ до `/stats` у боті (акаунт власника);
- секундомір.

Перед стартом: `npm test` (80 зелених) і `npm run i18n` (`Clean`) на тій самій
збірці, що в проді; `git log -1` збігається з задеплоєним комітом.
