# Sixtio — План виправлень (усі P0 і P1)

Джерело: `audit/AUDIT_REPORT.md`. Порядок — виконавчий, не за пріоритетом:
всередині одного пріоритету спочатку йде те, що **розблоковує вимірювання**
наступних кроків.

**Обмеження, які діють на КОЖЕН пункт:**
- Vercel Hobby cap = **12 serverless-функцій**. `api/` уже містить рівно 12.
  Новий серверний ендпоінт додається **тільки** через `op`-dispatch усередині
  наявного файлу. 13-й `api/*.js` кладе деплой.
- Зміна будь-якого зі спільних ассетів (`i18n.js`, `theme.js`, `paywall.js`,
  `theme.css`) вимагає **бампу `?v=` в усіх 11 HTML одночасно** (зараз `v=43`).
- Перед комітом: `npm test` (80 тестів) + `npm run i18n` (має бути `Clean`).
- Push у `main` — тільки за явним проханням власника.

**Разом:** P0 ≈ **5.5 дня** · P1 ≈ **6 днів** · юридичний трек — паралельно,
календарно ~1–2 тижні (залежить від юриста, не від розробки).
